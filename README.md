# abby - ジュエリー・時計・ブランド品の買取・卸販売

## 📋 プロジェクト概要

ジュエリー、時計、ブランドバッグの買取・卸販売を行う**株式会社abby**の公式ホームページです。

**コンセプト**: 「高価買取と豊富な在庫で、個人・法人のお客様をサポート」

---

## 🏢 会社情報

### 事業内容
- ジュエリー（ネックレス、リング、ピアス、ブレスレット等）の買取・卸販売
- 時計（ROLEX、OMEGA、Cartier等）の買取・卸販売
- ブランドバッグ（HERMES、CHANEL、LOUIS VUITTON等）の買取・卸販売

### ターゲット
- **個人のお客様**: 高価買取サービス
- **法人のお客様**: 卸販売サービス（小ロット〜大量発注対応）

## 📌 デザイン指示書

### 制作者向けの重要ポイント

1. **余白の使い方**
   - セクション間: 100px (PC) / 60px (スマホ)
   - 要素間: 40px〜60px
   - 商品カード間: 40px (PC) / 24px (スマホ)

2. **文字サイズ**
   - セクションタイトル: 28px (PC) / 24px (スマホ)
   - サブタイトル: 14px
   - 本文: 14px〜16px
   - 商品名: 14px

3. **配色ルール**
   - 背景は白を基本、薄いグレーでアクセント
   - 文字は黒を基本、グレーで補足
   - ゴールドはボタンやアイコンに使用

4. **画像の扱い**
   - 商品画像: 縦長 (120%比率)
   - ヒーロー画像: 横長 (600px高さ)

5. **ホバーアニメーション**
   - 商品カード: 上に4px移動
   - ボタン: 背景色・文字色の反転
   - リンク: アクセントカラーへ変化
